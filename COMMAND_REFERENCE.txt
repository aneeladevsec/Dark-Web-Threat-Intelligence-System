API TESTING - CURL COMMANDS
═════════════════════════════════════════════════════════════════════════════════

Basic Tests:
  
  Get Server Health:
    curl http://localhost:5002/health
  
  Get Statistics:
    curl http://localhost:5002/stats
  
  Get All Threats:
    curl http://localhost:5002/threats
  
  Get Recent Threats:
    curl http://localhost:5002/threats/recent
  
  Get Critical Threats:
    curl http://localhost:5002/threats/critical

Search & Query:
  
  Search for Ransomware:
    curl "http://localhost:5002/search?q=ransomware"
  
  Get Threat by ID:
    curl "http://localhost:5002/threats/THREAT-1F579AEC"

Analytics:
  
  Get Timeline Data:
    curl "http://localhost:5002/analytics/timeline?days=7"
  
  Get Predictive Insights:
    curl "http://localhost:5002/analytics/predictive"
  
  Get Advanced Metrics:
    curl "http://localhost:5002/analytics/advanced"
  
  Get Metrics by Type:
    curl "http://localhost:5002/threats/metrics/by-type"
  
  Get Metrics by Source:
    curl "http://localhost:5002/threats/metrics/by-source"

Export:
  
  Export as CSV:
    curl "http://localhost:5002/export/threats/csv" > threats.csv
  
  Export as JSON:
    curl "http://localhost:5002/export/threats/json" > threats.json

System:
  
  Get Alerts:
    curl "http://localhost:5002/alerts?limit=10"
  
  Get Geolocation:
    curl "http://localhost:5002/geo"
  
  Get Feed:
    curl "http://localhost:5002/feed"

═════════════════════════════════════════════════════════════════════════════════
API TESTING - POWERSHELL COMMANDS
═════════════════════════════════════════════════════════════════════════════════

Basic Tests:
  
  Health Check:
    (Invoke-WebRequest -Uri "http://localhost:5002/health" -UseBasicParsing).Content | ConvertFrom-Json
  
  Get Statistics:
    (Invoke-WebRequest -Uri "http://localhost:5002/stats" -UseBasicParsing).Content | ConvertFrom-Json | Select-Object -Property total_threats, critical_count
  
  Get Threats Count:
    $threats = (Invoke-WebRequest -Uri "http://localhost:5002/threats" -UseBasicParsing).Content | ConvertFrom-Json; $threats.total

Analytics:
  
  Predictive Insights:
    (Invoke-WebRequest -Uri "http://localhost:5002/analytics/predictive" -UseBasicParsing).Content | ConvertFrom-Json | Format-List

Data Export:
  
  Download CSV:
    Invoke-WebRequest -Uri "http://localhost:5002/export/threats/csv" -OutFile "threats.csv"
  
  Download JSON:
    Invoke-WebRequest -Uri "http://localhost:5002/export/threats/json" -OutFile "threats.json"

CONFIGURATION MANAGEMENT
═════════════════════════════════════════════════════════════════════════════════

View Current Settings:
  Use your favorite text editor to open: .env

Common Configuration Changes:

  Change API Port:
    Edit .env: PORT=5002  →  PORT=8000
    Then restart server
  
  Change API Authentication Key:
    Edit .env: API_KEY=threat-intel-api-key-test  →  API_KEY=my-custom-key
  
  Change Database Location:
    Edit .env: DB_PATH=threats.db  →  DB_PATH=/path/to/db/threats.db
  
  Change Cache TTL:
    Edit .env: CACHE_TTL=300  →  CACHE_TTL=600

Note: Restart server after any .env changes
