🔧 API ENDPOINTS (25+)

Core Threats:
  GET /threats                     - All threats
  GET /threats/recent              - Last 24h
  GET /threats/critical            - Critical only
  GET /threats/<id>                - Specific threat
  GET /threats/<id>/correlations   - Related threats

Analytics:
  GET /analytics/timeline          - Timeline data
  GET /analytics/predictive        - Predictions
  GET /analytics/advanced          - Full dashboard
  GET /threats/metrics/by-type     - Type metrics
  GET /threats/metrics/by-source   - Source metrics

Search & Query:
  GET /search?q=query              - Full-text search

Export:
  GET /export/threats/csv          - CSV download
  GET /export/threats/json         - JSON download

System:
  GET /health                      - Health check
  GET /stats                       - Statistics
  GET /geo                         - Geolocation
  GET /feed                        - Real-time feed
  GET /alerts                      - Alerts
  POST /incidents                  - Create incident

❓ TROUBLESHOOTING

Issue: API not responding
  → Ensure port 5002 is free
  → Check firewall settings
  → Verify Python installed

Issue: Frontend not loading
  → Check browser console (F12)
  → Verify API is running
  → Clear browser cache

Issue: Database error
  → Delete threats.db file
  → Restart API server
  → Automatic re-initialization

See full guide in README.md troubleshooting section
